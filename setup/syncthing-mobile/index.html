    Syncthing モバイル設定ガイド¶

    Syncthing を使うと、サーバーの downloads/ フォルダにある音楽ファイルをスマートフォンに自動同期できます。
    このページでは iPhone（iOS） と Android それぞれの手順をステップバイステップで説明します。

    全体の流れ¶

    1. スマホに同期用フォルダを作成する
2. スマホに Syncthing アプリをインストールする
3. スマホ側のデバイス ID を確認する
4. サーバー側の Syncthing にスマホを登録する
5. スマホ側でサーバーからのリクエストを承認する
6. 同期動作を確認する

    フォルダを先に作る

    Syncthing アプリ側でフォルダを後から指定する場合でも、スマホ側に同期先フォルダを先に作っておくと トラブルが少なくなります。手順の最初で作成してください。

    iPhone（iOS）の設定¶

    iOS では公式の Syncthing アプリが存在しないため、サードパーティ製クライアント Möbius Sync を使います。

    ステップ 1: iPhone に同期用フォルダを作成する¶

    「ファイル」アプリを使って同期先フォルダを事前に作成します。

    1. iPhone のホーム画面から 「ファイル」 アプリを開く
    2. 左下の 「ブラウズ」 タブをタップ
    3. 「この iPhone 内」 をタップ
    4. 右上の 「…」 → 「新規フォルダ」 をタップ
    5. フォルダ名（例: Music）を入力して 「完了」 をタップ

    フォルダの場所

    Möbius Sync のデフォルトは On My iPhone/Möbius Sync/ 以下にフォルダを作成します。
    「ファイル」アプリで Möbius Sync フォルダが見当たらない場合は、
    先に Möbius Sync をインストールしてから再度確認してください。

    ステップ 2: Möbius Sync をインストールする¶

    1. App Store を開き、「Möbius Sync」を検索
    2. アプリをインストール（有料アプリ、購入が必要）

    代替アプリについて

    iOS では Möbius Sync 以外に選択肢がほぼありません。
    完全無料で使いたい場合は、Android 端末の使用を検討してください。

    ステップ 3: iPhone のデバイス ID を確認する¶

    Möbius Sync を開いて自分のデバイス ID を確認します。

    1. Möbius Sync アプリを起動
    2. 画面下部の 「My Device」 タブをタップ
    3. 表示されている Device ID（XXXXXXX-XXXXXXX-... 形式）をメモする
      （「Share」ボタンでコピーまたは QR コードを表示できます）

    ステップ 4: サーバー側の Syncthing にスマホを追加する¶

    サーバー側の設定

    以降の操作はサーバーの Syncthing Web GUI で行います。
    デフォルトのアクセス先: http://localhost:8384
    外部から操作する場合は サーバー側の設定 を参照してください。

    1. ブラウザでサーバーの Syncthing GUI を開く（http://localhost:8384）
    2. 右側の 「リモートデバイスを追加」 をクリック
    3. 「デバイス ID」 欄にステップ 3 でメモした ID を貼り付ける
    4. 「デバイス名」 に分かりやすい名前（例: iPhone）を入力
    5. 「保存」 をクリック

    ステップ 5: 音楽フォルダをスマホと共有する¶

    1. Syncthing GUI の左側にある フォルダ一覧 から downloads/ フォルダ（または音楽用フォルダ）を選択
    2. フォルダ名の右にある 「編集」 をクリック
    3. 「共有」 タブをクリック
    4. ステップ 4 で追加した iPhone にチェックを入れる
    5. 「保存」 をクリック

    ステップ 6: iPhone 側でリクエストを承認する¶

    1. iPhone の Möbius Sync を開く
    2. 「Devices」 タブにサーバーからの追加リクエストが表示されているので 「Accept」 をタップ
    3. 「Folders」 タブにフォルダ共有リクエストが表示されたら 「Accept」 をタップ
    4. 同期先フォルダの入力欄で 「ステップ 1 で作成したフォルダ」 を選択して 「Save」 をタップ

    ステップ 7: 同期設定を調整する¶

    設定項目 推奨値 説明
    Run on Wi-Fi only 有効 モバイル通信でのデータ消費を防ぐ
    Run when charging 任意 バッテリーを節約したい場合に有効

    設定場所: Möbius Sync → 「Settings」 タブ

    iPhone での音楽再生¶

    同期が完了した音楽ファイルは、以下のアプリで再生できます。

    アプリ 特徴
    音楽（Apple Music アプリ） iOS 標準。外部フォルダの MP3 は「ファイル」から開けば再生できる
    VLC for iOS 無料・多フォーマット対応。フォルダ指定でライブラリ登録可能
    Doppler iOS 向けの音楽プレイヤー。「ファイル」アプリのフォルダを直接認識
    Flacbox FLAC/ハイレゾ対応。多フォーマット対応

    VLC での設定方法

    VLC → 「…」（その他） → 「ファイルから開く」 → 同期フォルダを選択すると、 フォルダ内の全ファイルがプレイリストに追加されます。

    Android の設定¶

    ステップ 1: Android に同期用フォルダを作成する¶

    ファイルマネージャーアプリを使って同期先フォルダを事前に作成します。

    1. 「ファイル」 アプリまたは端末のファイルマネージャーを開く
    2. 内部ストレージを開く（「内部ストレージ」「This device」などの表示）
    3. Music フォルダを開く（存在しない場合は新規作成）
    4. 右上の 「新規フォルダ」 をタップ
    5. フォルダ名（例: SyncTuneHub）を入力して作成

    フォルダパスの例

    /storage/emulated/0/Music/SyncTuneHub
    Syncthing でフォルダを設定する際にこのパスを使います。

    ステップ 2: Syncthing アプリをインストールする¶

    Syncthing を検索してインストール

    Syncthing または
    Syncthing-Fork（バッテリー最適化改善版）をインストール

    Syncthing-Fork の利点

    F-Droid の Syncthing-Fork はバッテリー効率の改善が加えられており、バックグラウンド動作が安定しています。
    バッテリー消費が気になる場合はこちらを推奨します。

    ステップ 3: Android のデバイス ID を確認する¶

    1. Syncthing アプリを起動
    2. 画面上部のハンバーガーメニュー（☰）→ 「マイデバイス」 をタップ
    3. 画面下部に表示されている デバイス ID をメモする
      （「共有」ボタンで QR コードを表示してサーバー側のカメラで読み取ることも可能）

    ステップ 4: サーバー側の Syncthing にスマホを追加する¶

    iPhone のステップ 4 と同じ操作です。

    1. サーバーの Syncthing GUI を開く（http://localhost:8384）
    2. 右側の 「リモートデバイスを追加」 をクリック
    3. 「デバイス ID」 にステップ 3 でメモした ID を入力
    4. 「デバイス名」 に分かりやすい名前（例: Android）を入力
    5. 「保存」 をクリック

    ステップ 5: 音楽フォルダをスマホと共有する¶

    iPhone のステップ 5 と同じ操作です。

    1. Syncthing GUI のフォルダ一覧から downloads/ を選択 → 「編集」
    2. 「共有」 タブで Android にチェックを入れる
    3. 「保存」 をクリック

    ステップ 6: Android 側でリクエストを承認する¶

    1. Android の Syncthing アプリを開く
    2. デバイス追加リクエスト が届いていたら 「承認」 をタップ
    3. フォルダ共有リクエスト が届いたら 「承認」 をタップ
    4. 「フォルダのパス」 欄を ステップ 1 で作成したフォルダのパス に変更する
      （例: /storage/emulated/0/Music/SyncTuneHub）
    5. 「保存」 をタップ

    フォルダパスは必ず確認する

    デフォルトのパスは Syncthing の内部フォルダになります。
    音楽プレイヤーがスキャンできるフォルダ（Music/ 以下など）に変更してください。

    ステップ 7: 同期設定を調整する¶

    設定項目 推奨値 説明
    Wi-Fi のみで同期 有効 モバイル通信でのデータ消費を防ぐ
    充電中のみ同期 任意 バッテリーを節約したい場合に有効
    常に実行 任意 バックグラウンド同期を継続する

    設定場所: Syncthing アプリ → メニュー（⋮）→ 設定 → 同期条件

    Android での音楽再生¶

    同期が完了した音楽ファイルは、以下のアプリで再生できます。

    アプリ 特徴
    VLC for Android 無料・多フォーマット対応（MP3/FLAC/AAC/OGG すべて対応）
    Poweramp 高音質・多機能（有料）
    Musicolet 軽量・広告なし・無料

    同期先フォルダ（例: /storage/emulated/0/Music/SyncTuneHub）を音楽プレイヤーのライブラリに追加してください。

    サーバー側の Syncthing 設定（詳細）¶

    Syncthing Web GUI へのアクセス¶

    環境 アクセス先
    サーバーに直接ログインしている場合 http://localhost:8384
    SSH でアクセスしている場合 ssh -N -L 8384:localhost:8384 user@サーバーIP を実行後、http://localhost:8384
    Docker で動かしている場合 docker compose のポート設定次第（デフォルトは 8384:8384）

    サーバーのデバイス ID を確認する¶

    スマホ側から先にサーバーを追加したい場合に使います。

    1. Syncthing GUI を開く
    2. 右上の 「アクション」 → 「ID を表示」 をクリック
    3. 表示された QR コードまたは文字列がサーバーのデバイス ID

    共有フォルダの設定項目¶

    フォルダの 「編集」 ダイアログにある主な設定項目：

    項目 説明 推奨値
    フォルダ ID Syncthing 内部で使う一意の ID 変更不要
    フォルダのラベル GUI 上の表示名 music など任意
    フォルダのパス サーバー上の実際のパス downloads/ 以下の絶対パス
    フォルダタイプ 同期の方向性 「送信のみ」 を推奨
    監視ファイルシステム ファイル変更を自動検出 有効
    再スキャン間隔（秒） フォルダを再スキャンする頻度 3600（1時間）など

    フォルダタイプ「送信のみ」を推奨

    サーバーからスマホへの一方向転送で使う場合、フォルダタイプを 「送信のみ（Send Only）」 に設定すると、 スマホ側でファイルを削除してもサーバー側には影響しません。

    追加したリモートデバイスの一覧が表示されます。チェックを入れたデバイスにフォルダが共有されます。

    各デバイスに対して 暗号化パスワード を設定することもできます（エンドツーエンド暗号化）。

    同期から除外するファイルを指定できます。例：

    // サムネイルや一時ファイルを除外する例
*.jpg
*.png
*.tmp
.DS_Store
    項目 説明
    同期順序 ランダム、最新順、最古順などを選択可能
    ファイルのプル順序 転送優先度の設定
    最大同期変更量 誤削除などの暴走を防ぐ安全装置

    API キーを .env に設定する¶

    Syncthing のステータスをアプリから確認するために、API キーを設定します。

    1. Syncthing GUI → 右上の 「アクション」 → 「設定」 をクリック
    2. 「API キー」 欄に表示されているキーをコピー
      （「更新」ボタンで新しいキーを生成することも可能）
    3. .env に設定する
    SYNCTHING_URL=http://localhost:8384
SYNCTHING_API_KEY=（コピーした API キー）

    リモートデバイスの管理¶

    デバイスの接続状態を確認する:
    Syncthing GUI の右側「リモートデバイス」欄に、接続中・切断中のステータスが表示されます。

    デバイスを削除する:
    デバイス名の右にある 「編集」 → 「削除」 をクリックします。

    トラブルシューティング¶

    デバイスが接続されない¶

    • スマホとサーバーが 同じネットワーク（Wi-Fi） にいるか確認する
    • サーバーの Syncthing のファイアウォールでポート 22000（TCP/UDP）が開いているか確認する
    # ポート確認（サーバー側）
sudo ss -tlnp | grep 22000

    リクエストがスマホ側に届かない¶

    • スマホアプリを一度終了して再起動する
    • 双方の Syncthing が起動中かを確認する
    • デバイス ID に入力ミスがないか再確認する（コピー＆ペーストを使うことを推奨）

    フォルダが同期されない / 「同期外れ」と表示される¶

    フォルダタイプを 「送信のみ」 に設定している場合、スマホ側でファイルを削除したときに サーバー側の Syncthing GUI に 「同期外れ」 と表示されることがあります。これは正常な動作です。

    スマホから削除したファイルをサーバーで再送したい場合:

    1. Syncthing GUI でフォルダを開く
    2. 「同期外れアイテムを無視する」 または 「削除済みファイルを復元」 をクリック

    iPhone（Möbius Sync）が同期を開始しない¶

    • iOS はバックグラウンド動作に制限があるため、Möbius Sync はアプリがフォアグラウンドにある間しか同期しません
    • 大きなファイルを同期する場合は、アプリを開いたままスリープしないようにしてください
    • 「Background Refresh」 を有効にすると、一定間隔でバックグラウンド同期が試みられます
      設定場所: iOS 「設定」 → 「一般」 → 「Appのバックグラウンド更新」 → 「Möbius Sync」 をオン

    外出先からも同期したい¶

    自宅 LAN 外から同期する場合は Syncthing のリレーサーバー機能を使うか、VPN を設定します。

    1. Tailscale をサーバーとスマホ両方にインストール
    2. 同じアカウントでログイン
    3. Tailscale が割り当てた IP アドレスで Syncthing が自動的に接続する

    Syncthing はデフォルトでグローバルリレーサーバーを使って NAT を越えた通信を行います。
    特別な設定は不要ですが、リレー経由では転送速度が低下する場合があります。

    まとめ¶

    やりたいこと 設定
    iPhone に音楽を同期したい Möbius Sync（有料）+ サーバー側でデバイス追加
    Android に音楽を同期したい Syncthing または Syncthing-Fork + サーバー側でデバイス追加
    スマホで削除してもサーバーに影響させたくない サーバー側フォルダタイプを「送信のみ」に設定
    バッテリーを節約したい 「充電中のみ・Wi-Fi のみ」に設定
    外出先でも同期したい Tailscale などの VPN を利用
    ダウンロードされた曲を自動転送したい downloads/ フォルダを共有フォルダとして設定
