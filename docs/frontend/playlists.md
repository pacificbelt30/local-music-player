# プレイリストパネル

`frontend/js/playlists.js` は認証案内、アカウントからの追加、同期一覧、詳細の表示を担当します。`sync-tracks.js` は曲一覧のページ・検索状態を保持します。

## 読み込みのタイミング

同期一覧は同期タブを初めて開いたときに取得し、表示中は5秒ごとに更新します。画面やブラウザのタブが非表示の場合は自動取得しません。認証状態は設定または追加欄を開いたとき、アカウントの一覧は追加欄の「アカウントから選ぶ・個別に追加」を開いたときに取得します。設定変更や通常の同期更新ではアカウント一覧を取り直しません。

認証後はOAuthコールバックで認証情報を保存します。非公開プレイリストはAPI同期を選択でき、公開・限定公開の共有URLからも追加できます。既定の取得方式・形式・品質は設定を使い、今回だけ上書きできます。

## 同期一覧と詳細

カードを押すと詳細が開きます。自動更新では同じカードと曲の行を維持し、開いた詳細・エラー・フォーカス・スクロール位置を保持します。一時停止、手動同期、削除の成否は操作した場所で案内します。

詳細で曲一覧を展開すると、最初の50曲を取得します。「前へ」「次へ」で移動し、タイトル・アーティストと状態で絞り込めます。自動更新も現在のページと条件を使います。通信失敗では既存の行を残して再試行を表示し、閉じたときは処理中の取得をキャンセルします。非表示・削除などで遅れて返る応答も、現在の一覧を上書きしません。

`GET /youtube/syncs/{id}/tracks/page?limit=50&offset=0&search=...&status=...` の応答は `{items,total,offset,limit}` です。元の全件取得APIも互換性のため維持します。並び順は `position,id`、対象は `status != removed` です。

初期化と画面単位の取得は `app.js` と `panel-lifecycle.js` が管理します。取得済みの画面へ戻っても初期化を繰り返しません。
